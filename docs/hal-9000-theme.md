# HAL 9000

Select **HAL 9000** in **Butler Dashboards → Displays → Theme**, then save the display assignment. Install an Android app built from the accompanying HAL changes and update the integration before selecting it. The stored theme ID is `hal_9000`.

The Android presentation uses charcoal panels, warm white text, red accents, and a brushed aluminum faceplate with a red optical lens and speaker grille. The lens glow responds to listening, thinking, transcribing, and speaking. Tap the lens to use the existing voice control. The animation follows the app's Reduced and Off motion settings.

Existing dashboard layouts, assistant names, and voice pipelines remain configured separately. This theme supplies appearance only; it does not install a HAL voice or change the assistant's personality. The Home Assistant layout editor includes a static lens preview. All artwork is drawn locally in code without downloaded assets.

Validation: Android debug build and unit tests; Home Assistant profile/store tests; frontend JavaScript syntax check. A physical display preview is still needed before release.
